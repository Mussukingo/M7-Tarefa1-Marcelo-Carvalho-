
# Caldays - Feriados de Portugal

## API utilizada
Caldays API

Endpoint:
https://caldays.com/api/holidays/PT

## Método HTTP
GET

## Linguagem e framework
- JavaScript com React

## Campos extraídos do JSON
- País;
- Ano;
- Quantidade de feriados;
- Nome do feriado;
- Data do feriado.

## Funcionalidades
- Requisição HTTP GET com fetch().
- Parse da resposta JSON.
- Apresentação dos feriados no React.
